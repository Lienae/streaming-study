프로토콜

RTSP

카메라 영상을 외부로 내보내는 프로토콜.
실제 영상은 RTP가 전송하고 RTSP는 제어 역할을 담당한다.

기본 포트 : 554
변환

HLS

브라우저는 RTSP를 직접 재생하지 못한다.

• .m3u8 : 플레이리스트
• .ts : 영상 조각 파일

m3u8이 지속적으로 갱신되며 실시간 스트리밍처럼 동작한다.
